# Student Depression Analysis

## Project Overview
This project focuses on analyzing the relationship between students' lifestyle factors and depression levels. The goal is to identify key patterns and risk factors that may influence mental health.

## Objectives
- Explore the dataset using Exploratory Data Analysis (EDA)
- Identify correlations between lifestyle and depression
- Visualize key trends and patterns
- Apply statistical analysis methods

## Technologies Used
- Python
- Pandas, NumPy
- Matplotlib, Seaborn
- Jupyter Notebook

## Dataset
- Student Depression Dataset (~27,000 records)
- Includes features such as sleep, academic pressure, lifestyle habits, and mental health indicators

## Key Analysis
- Data cleaning and preprocessing
- Correlation analysis
- Statistical testing (t-test, ANOVA)
- Regression analysis
- Data visualization

## Key Insights
- Students with poor sleep quality show significantly higher depression levels
- Academic pressure positively correlates with depression
- Lifestyle factors (sleep, habits) have strong influence on mental health
- Social and behavioral factors impact depression more than expected

## Business Value
This analysis can help:
- Educational institutions identify at-risk students
- Improve student support and mental health programs
- Support data-driven decision making in education
